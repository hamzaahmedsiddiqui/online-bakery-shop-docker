## 🍪 BakeWell — Wholesome Baking for Mindful Living
BakeWell is a health-focused bakery brand and WordPress website dedicated to creating gentle, nourishing baked goods—with a special focus on mothers, women, and mindful eaters.

The brand is built around trust, simplicity, and care. Every product and every page is designed to feel calm, reassuring, and transparent.

## 🌸 Brand Philosophy
BakeWell believes that food should:
	•	Feel safe and comforting
	•	Use simple, honest ingredients
	•	Be inclusive of dietary needs
	•	Support everyday nourishment without medical claims

The brand prioritizes mother-first baking, while also serving women, families with egg allergies, vegan customers, and those seeking balanced protein snacks.


### Use your preferred IDE to run the project

If you want to work locally using your own IDE, you can clone this repo and push changes. Pushed changes will also be reflected in Lovable.

The only requirement is having Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

Follow these steps:

```sh
# Step 1: Clone the repository using the project's Git URL.
git clone https://github.com/hamzaahmedsiddiqui/Bake-Well.git

# Step 2: Navigate to the project directory.
cd /Bake-Well

# Step 3: Install the necessary dependencies.
npm i

# Step 4: Start the development server with auto-reloading and an instant preview.
npm run dev
```
